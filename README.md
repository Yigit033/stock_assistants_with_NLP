# Stock Assistants with NLP

A Python-based project leveraging Natural Language Processing (NLP) to create intelligent stock market assistants. The system integrates multiple financial data sources to provide comprehensive stock analysis and recommendations.

## Key Features
- **Multi-source Data Integration**: Fetches and processes stock data from:
  - Yahoo Finance (YFinance)
  - Alpha Vantage API
- **NLP-powered Analysis**: Employs natural language processing techniques to:
  - Interpret market trends
  - Generate investment insights
  - Provide actionable recommendations
- **Assistant Ecosystem**: Includes three specialized stock analysis assistants with distinct functionalities
